# Repository Test Scripts

This file describes the purpose of each autogenerated test script.

- `tests/test_dataloader_efficiency.py`
  - Verifies that `Segmentation_Dataset` and `DataLoader` are configured for efficient batch preparation.
  - Checks `num_workers`, `persistent_workers`, `prefetch_factor`, and basic tensor shapes/types.

- `tests/test_train_eval_wrapper.py`
  - Runs an end-to-end training session using the U-Net based `InstanSeg_UNet` model.
  - Verifies that `InstanSegModel.train(...)` and `InstanSegModel.eval(...)` work, and that the saved `runs/<experiment>/config.yaml` reflects overridden config values.

- `tests/test_reproducibility.py`
  - Executes two independent, seed-matched training sessions and compares final model weights and metric histories.
  - Confirms the pipeline is deterministic for the same config and seed.

- `tests/test_resume_training.py`
  - Trains a model for one epoch, then resumes training from the saved checkpoint.
  - Verifies that resume mode respects the total epoch target and writes the metrics checkpoint history.

## Running the tests

Run each file from the repository root, for example:

```bash
python tests/test_dataloader_efficiency.py
python tests/test_train_eval_wrapper.py
python tests/test_reproducibility.py
python tests/test_resume_training.py
```

These scripts are intentionally end-to-end and should be executed from the repository root so the package imports and relative data paths resolve correctly.
